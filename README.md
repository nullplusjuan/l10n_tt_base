# Trinidad and Tobago - Base Localization

Foundation localization module for Odoo 18.

It currently provides Trinidad and Tobago first-level subdivision records for `res.country.state` using ISO-style subdivision codes. It deliberately does **not** install a chart of accounts, tax rules, payroll rules, or statutory identifiers; those should be implemented as separate localization modules after the relevant legal/accounting requirements are specified and verified.
